# Proposed QC Checks

This directory contains standalone Python implementations for each quality control flag in the FVON-QCQA system.

## Purpose

These files are designed for:
- Team review and discussion
- Individual testing of each QC check
- Documentation of QC methodologies
- Easy integration into data processing workflows

## Usage

Each file can be run standalone:

```python
from flag_impossible_date import flag_impossible_date
import pandas as pd

df = pd.read_csv('your_data.csv')
df = flag_impossible_date(df)
print(df['flag_impossible_date'])
```

Or run the file directly to see examples:

```bash
python flag_impossible_date.py
```

## Integration

## Dependencies

Common dependencies across all files:
- `pandas`
- `numpy`

Additional dependencies for specific tests:
- `geopandas`, `shapely`, `pyproj` - for `flag_position_on_land.py`
- `geopy` - for `flag_impossible_speed.py`, `flag_gear_type.py`

## Flag Value Convention

All QC checks follow this convention:
- `1` = Pass (good data)
- `2` = Not evaluated (when applicable)
- `3` = Suspect (questionable data)
- `4` = Fail (bad data)
